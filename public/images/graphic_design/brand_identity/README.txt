VANTA MOTION CASE STUDY IMAGES

Place your exported PNG images in this folder using this filename pattern:

vanta_motion1.png
vanta_motion2.png
vanta_motion3.png
...

The portfolio automatically checks vanta_motion1.png through vanta_motion40.png.
Missing numbers are skipped automatically, so it is okay if a number such as
vanta_motion13.png does not exist.

Recommended export:
- PNG or high-quality JPG (update the extension in script.js for JPG)
- 1600–2400 px wide
- sRGB
- Compress images before deployment for faster loading
